# DELA'S WORLD

Mini mundo de diversão com moda e estilo: um quiz para descobrir sua vibe e um organizador de looks.

**Autora:** [NOME DA ALUNA] · Projeto escolar, 3ª série

**Acesse:** https://professoralissonlucas.github.io/delasworld/

## Como usar

1. Abra o site pelo link acima ou abra o arquivo `index.html` no navegador.
2. **Qual é a sua Vibe?** — responda às 5 perguntas e veja o seu dossiê de estilo (+10 estrelas).
3. **Organizador de Looks:**
   - **Guarda-roupa:** envie fotos das suas roupas (JPG, PNG ou WEBP).
   - **Combinar uma peça:** escolha uma peça (do catálogo ou sua) e clique em "Encontrar combinações" para ver 3 looks completos.
   - **Meus looks:** veja os looks montados e os favoritos.

As peças enviadas ficam salvas só no seu navegador.

## Feito com

HTML, CSS e JavaScript puro, sem frameworks.
